# Visual-review gameplay outside the long soak: a campaign mission or the
# Practice Range, entered the way a person does and driven by real pad input
# (no qualification auto-driver). The package URL picks the scene, and its
# qualification=visual loads qualification.js for the companion's
# __treadlineDebug (the killcam stays on, as in ordinary play):
#   ?qualification=visual&visual=mission&mission=N   campaign mission N (0 = 1-1), Veteran
#   ?qualification=visual&visual=range               Practice Range, free range
# Recorded with scripts/run-ppsspp-input-script.sh --measure --record-video
# for scripts/visual-review.py; there is no golden (input timing varies).
#
# The companion opens the mission briefing or the drill list with the
# primary button focused once the runtime is ready; Cross is then a trusted
# activation that claims Page controls, so play runs full screen.
