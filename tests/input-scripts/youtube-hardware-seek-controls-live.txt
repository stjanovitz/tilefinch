# DEVICE-LOOP SCRIPT -- NOT A GOLDEN-GATED SCENARIO.
#
# Exercise the two PSP-specific seek controls after natural autoplay is
# established.  A shoulder press creates a coarse preview; Cross commits it.
# The analog nub then creates a second preview; Cross commits that one too.
# Long post-commit windows distinguish slow re-prime from a stuck session.
wait-live 2400
mark-live autoplay
tap-live rtrigger
wait-live 2
mark-live shoulder-preview
tap-live cross
wait-live 1800
mark-live shoulder-committed
stick-live 20 right
wait-live 2
mark-live nub-preview
tap-live cross
wait-live 1800
mark-live nub-committed
tap-live circle
wait-live 180
end
