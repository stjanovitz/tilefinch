# Start the way a player does. The long-soak page opens on Quick Match with
# Deploy focused; once the runtime is ready (treadline-long-soak.until.js),
# Cross is a trusted click on Deploy that claims Page controls, so the match
# runs full screen with no browser chrome over the canvas. Under Page
# controls each script frame is one 30 Hz game frame.
until 900
tap-live cross
# Onslaught (and Daily) forge their arena after Deploy; how long that takes
# depends on the seed. The same probe now waits for play to begin.
mark-page deployed
until 900
# Before the window, the game's JavaScript phase clocks profile 180 frames
# and the companion returns their report: attribution work that used to land
# inside the window (the report alone cost a 60 ms frame).
wait-live 60
mark-page profile-start
wait-live 240
mark-page profile-report
# The five-second PAGE CONTROLS ON toast ended during the profile above; this
# wait keeps the window's position (and the golden's frame count) unchanged.
wait-live 60
# Page marks fall between frames, so the reset never splits a frame. The
# companion turns the phase clocks off for the window.
mark-page webgl-measure-start
# About 45 seconds: the long-soak qualification mode drives the player
# through bounded combat, obstacle avoidance, and repeated action events
# while it cycles arenas.
wait-live 1350
mark-page webgl-measure-end
wait-live 10
end
